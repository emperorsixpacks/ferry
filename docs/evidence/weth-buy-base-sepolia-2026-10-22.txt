# Ferry: the first WETH -> ZEC buy on public test networks, 2026-10-22. One swap through the public
# web card of the server deploy, on Base Sepolia (chain 84532) and the Zcash testnet.
#
# What ran: the same stack as docs/evidence/local-stack-base-sepolia-2026-10-21.txt
# (`infra/deploy/deploy.sh local`, compose project "ferry-local", Caddy on https://localhost:7950,
# public mode: FERRY_OWN_NODE unset), restarted on 2026-10-22 with its volumes and keys. Code:
# 0b08ba9 (the code of the 10-21 final checks). Settings unchanged from that file:
# BUY_ZEC=btc,ltc,usdc-base,weth-base, WETH_RATE 0.012 WETH per ZEC, swaps of 0.01-0.25 ZEC, the
# demo guard's defaults (0.5 ZEC a swap, 3 swaps per IP and 12 in all per hour).
# The swap was started by a headless Chromium (Playwright) using the swap card itself: press
# "Switch direction" (receive ZEC), pick WETH, type 0.01, press Buy ZEC; the progress page was

# swap starts on the pair's B (bram, holds WETH) and the pair's Z (zoe) is the maker selling ZEC.
