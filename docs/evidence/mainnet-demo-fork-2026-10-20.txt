# Ferry + NEAR Intents mainnet demo, rehearsed on a fork of Base mainnet, 2026-10-20
# (infra/mainnet-demo.sh). Nothing in this file sent a real transaction or created a real 1Click quote.
#
# anvil 1.5.1 forking https://mainnet.base.org on 127.0.0.1:18576 with 2 s blocks and Base's base
# fee read from the live chain. The chain id stays 8453, so both ferryd daemons applied the Base
# MAINNET policy (1 h margins, 30 lock confirmations, 10 ZEC confirmations, t1 = 5 h 15 min).
# USDC: Circle's real contract on Base (0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913) in its forked
# state; B's 50 USDC were moved from a real holder by impersonation (found in Transfer logs read
# from https://base-rpc.publicnode.com, since mainnet.base.org refuses eth_getLogs). ETH:
# anvil_setBalance with the amounts the owner is asked to fund (deployer 0.001, B 0.0005, Z 0.0002).
# FerryLock: deployed by the script from the committed artifact, after checking it against a
# fresh forge build, and its code on chain checked against the artifact.
# ZEC side: ferryd's mock Zcash chain with --zec-network main (a block every 3 s instead of 75 s).
# NEAR Intents: the real 1Click API, read-only (its token list and DRY quotes, signatures checked),
# for the numbers; the Ferry swaps paid into deposit addresses of the mock 1Click
# (web/mock/oneclick.mjs), which the script told about each deposit once the claim had landed
# on the fork. The second sell is refunded through the mock's fault switch; in the third, Z stalls
# after locking its ZEC and the fork's clock jumps to t1.
# The job lines say "signed by 1Click": on the fork that is the mock's own ed25519 key, which the UI
# server was told to check (FERRY_NEAR_PUBKEY); the real 1Click dry quotes were checked against 1Click's.
# The explorer links are where the transactions would be on the real networks; here they exist
# only on the fork and in the mock. Timeline times are local (UTC+1); "# started/ended" are UTC.
