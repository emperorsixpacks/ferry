# Ferry: the server deploy (infra/deploy) run on a Mac, 2026-10-21. Swaps through the public web UI
# on Base Sepolia (chain 84532) and the Zcash testnet: ZEC -> USDC, USDC -> ZEC, ZEC -> WETH,
# and up to three swaps at once on one pair.
#
# What ran: `infra/deploy/deploy.sh local` (docs/DEPLOY.md, "Rehearse locally"): the server's own
# compose file, images, private networks, read-only containers, secrets and public-demo guard
# (web/server/prod.mjs, public mode: FERRY_OWN_NODE unset, TRUST_PROXY=1), as compose project
# "ferry-local". The one difference, infra/deploy/compose.local.yml: Caddy serves
# https://localhost:7950 on 127.0.0.1 only, with its own local CA, instead of 80/443 with Let's
# Encrypt. DOMAIN=localhost:7950, so PUBLIC_ORIGIN is that page. The swaps were started by a
# headless Chromium (Playwright) using the swap card itself: pick the coin, type the amount, press
# Sell ZEC / Buy ZEC. Their progress was read back through the same web server
# (GET /daemon/<pair>/api/swaps/<id>), as the page does.
# Machine: Apple silicon Mac (arm64), Docker 29.1.3 (Docker Desktop, containerd image store),
# compose 2.40.3, 8 GB and 10 CPUs for Docker; partly on battery, on a slow and dropping network.
# Code: this branch (worktree-agent-a671a2a06215e8cec) with master merged. Swaps 1-2: master
# c18e053 (several swaps at once). Swaps 3-4: master fa618c2 (its review fixes) plus this branch's
# a0b5460 and 579a389. Swaps 5-7, the final code: master 2cd42a8 (finished swaps settle; reads don't
# wait for a daemon's round) merged in.
# Settings (infra/deploy/.env, no secrets): COMPOSE_PROFILES=ltc,usdc-base,weth-base;
# BUY_ZEC=btc,ltc,usdc-base,weth-base (visitors may also buy ZEC); MAX_SWAPS empty (ferryd's
# default, 4); the defaults for rates and sizes (40 USDC and 0.012 WETH per ZEC, 0.01-0.25 ZEC)
# and EVM deadlines (t1 45 min, refund window 30 min, margins 5 min, 10 lock confirmations); the
# demo guard's defaults (0.5 ZEC a swap, 3 swaps per IP and 12 in all per hour), except
# DEMO_SSE_PER_IP=200 and DEMO_SSE_TOTAL=2000 (Docker Desktop's port forwarding holds closed
# event streams for minutes: DEPLOY.md, "Rehearse locally").
# Wallets: ZEC/USDC runs the Base Sepolia accounts and Zcash wallets of the 2026-10-20 live swap
# (moved from .evm-testnet, whose daemons were stopped first): B 0x63311aC7fb54eebAbDdE5ee2e99971c7b8d6E4bD,
# Z 0x95713ff5BC7973166F3285Ed1b0574b1A24ec55a, so its Activity starts with that swap. ZEC/BTC runs
# the .testnet wallets, moved with `deploy.sh local migrate-wallets` (Z holds the 1 TAZ). ZEC/WETH
# has fresh accounts from `ctl secrets`: B 0x8908B7bd0c6153121578f6ac78bF81069587B591,
# Z 0x4F6fF6162FA23883DCe2EadC9821113971f458AE.

# Times are UTC. Zcash transactions are shielded, so they are given as txids only.

## Problems found on this run, and what was done
# Fixed on this branch:
# - ferryd crash-looped after a redeploy ("no spending account in the wallet: attempt to write a
#   readonly database"): stopping the container had killed zcash-devtool mid-write, and a
#   read-only connection can't roll back the hot journal it left. ferry-zec rolls it back at start
#   (a0b5460, with a test); ferryd-b then started on its own.
# - An empty MAX_SWAPS crash-looped every daemon (ferryd refuses an empty --max-swaps): compose
#   passes it only when set (99c72f9).
# - The healthcheck (ferry-api) had no time limit: while a daemon was slow, hung checks piled up
#   (10 after 5 minutes) and `deploy.sh status` hung (579a389).
# - deploy.sh migrate-wallets' EXIT trap named a local variable, so the temp file the private keys
#   pass through was never removed and a successful run exited 1 (942697f).
# - deploy.sh status printed Python tracebacks while a daemon was down (098d384).
# - The progress page could show the maker's copy of the visitor's swap (aa5004c, f32a8a8).
# Found here and fixed on master by others: finished swaps never settled without a Zcash node RPC,
# so every round re-polled them under the state lock and the USDC daemons stopped answering on the
# slow network (2cd42a8; after it, status and swaps answered in about 1 ms).

# upstream timeout on proxied GETs); a used firm quote stays cached, so the next start in its
# bucket within its ~45 s life is refused once; with Docker Desktop, closed tabs hold their event
# stream slot for 6+ minutes (local only: DEPLOY.md, "Rehearse locally").
